# 배경 사진 넣는 곳 (family-ritual.html)

「우리 가족의 특별한 날」 앱의 **배경만** 사진으로 바꿀 때 쓰는 폴더입니다.
인물(얼굴·몸)은 그대로 있으므로 **얼굴 위치를 맞출 필요가 없습니다.**

## 넣는 방법

### 방법 1 — 모든 기기에 한 번에 적용 (이 폴더)

1. 배경 사진을 이 폴더에 넣습니다. (예: `sebae.jpg`)
2. `backgrounds.json` 에 파일 이름을 적습니다.

```json
{ "s1": "sebae.jpg", "s2": "wedding.jpg", "s3": "funeral.jpg", "s4": "charye.jpg" }
```

3. 깃허브에 올리면 학생 기기 모두에 적용됩니다.

| 키 | 장면 |
|----|------|
| s1 | 설날 세배 |
| s2 | 결혼식 |
| s3 | 장례식 |
| s4 | 차례 |

### 방법 2 — 이 기기에서만 (앱 안에서)

각 장면의 **🖼️ 배경** 버튼 → 사진 고르기. 그 기기에만 저장됩니다.
되돌리려면 같은 버튼을 다시 누르거나 **🧹 배경 되돌리기** 를 누릅니다.

## 인물이 서는 자리 조정

사진 배경일 때는 인물 위치가 그림 배경일 때와 달라야 하므로,
`family-ritual.html` 안의 `FIG` 표에서 장면별로 따로 정해 둡니다.

```js
const FIG = {
  s1:{ plain:'',                 photo:'translate(68,179) scale(0.78)' },
  ...
};
```

`translate(x,y)` 는 오른쪽·아래로 옮기는 값, `scale` 은 크기입니다.
인물이 사진 속 사람과 겹치거나 붕 떠 보이면 이 숫자만 바꾸면 됩니다.

## 사진을 고르거나 만들 때

- **가로 4:3** (예: 1280×960). 다른 비율이면 가운데를 잘라 씁니다.
- **가운데~앞쪽이 비어 있어야** 합니다. 그 자리에 학생이 서거나 앉습니다.
  - s1 세배 / s4 차례 : 아래 가운데가 비어 있어야 함
  - s2 결혼식 : **왼쪽 앞**이 비어 있어야 함 (오른쪽 뒤에 신랑신부가 보이는 사진)
  - s3 장례식 : 가운데가 비어 있어야 함
- 사람이 이미 크게 찍힌 사진은 피합니다. 학생과 겹칩니다.
- 인물은 그림체이므로, 배경도 **일러스트풍**이 더 잘 어울립니다.
  사진처럼 사실적인 배경을 쓰면 인물만 만화처럼 떠 보일 수 있습니다.
