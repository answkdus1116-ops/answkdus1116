# 맛있는 김장 체험 — 그림 출처

이 앱의 그림은 **직접 그린 것**과 **openclipart 의 CC0 그림**을 섞어 씁니다.
CC0 는 출처를 밝히지 않아도 되지만, 어디서 왔는지 적어 둡니다.

## 직접 그린 그림 (이 앱을 위해 그렸습니다)
cabbage.svg (배추) · cabbage-salted.svg (절임배추) · kimchi.svg (김치) ·
onion.svg (파) · powder.svg (고춧가루) · fishsauce.svg (멸치액젓) ·
saltedshrimp.svg (새우젓) · bowl-paste.svg (양념 그릇)

장독, 그릇, 장바구니, 단풍나무, 가을 마당은 `kimjang.html` 안에 직접 그려 넣었습니다.

## 참고한 것
배추·무·파 그림을 openclipart 에서 찾아봤지만, 대부분 사람 캐릭터가 들어 있거나
김치와 무관한 그림이었습니다. 그래서 김장 재료는 직접 그렸습니다.
