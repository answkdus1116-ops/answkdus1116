# 눈사람 만들기 — 꾸미기 조각

`snowman.html` 에서 쓰는 그림들입니다. 자리와 크기는 `deco.js` 에 적혀 있습니다.

## 1. 직접 그린 그림 (이 앱을 위해 새로 그렸습니다 · 마음껏 쓰셔도 됩니다)

| 파일 | 무엇 |
|---|---|
| hat-santa.svg | 산타 모자 |
| hat-beanie.svg | 털모자 (방울 달린) |
| hat-top.svg | 중절모 |
| hat-earmuff.svg | 귀마개 |
| scarf-red / blue / green / cream .svg | 목도리 네 가지 색 |
| mitten-red / mitten-blue .svg | 벙어리장갑 |
| coal.svg | 숯 (눈·단추) |
| stone.svg | 돌멩이 (눈) |
| eyes-googly.svg | 움직이는 눈 |
| button-red / button-wood .svg | 단추 |
| branch / branch-dark .svg | 나뭇가지 팔 |
| smile-coal / smile-happy .svg | 입 |

openclipart 에서 모자·목도리를 찾아봤지만 쓸 만한 낱개 그림이 없었습니다
(대부분 사람이나 눈사람이 통째로 그려진 그림이었습니다).
그래서 이 조각들은 새로 그렸고, 덕분에 그림체가 서로 잘 어울립니다.

## 2. openclipart 에서 받아온 그림 (모두 CC0 · 퍼블릭 도메인)

openclipart 의 그림은 전부 CC0 라서 출처를 밝히지 않아도 되지만,
어디서 왔는지 알 수 있도록 적어 둡니다.

| 파일 | 원본 |
|---|---|
| oc-santa-hat.svg | https://openclipart.org 'santa hat' 검색 결과 |
| oc-carrot-a.svg · oc-carrot-b.svg · oc-carrot-c.svg | https://openclipart.org 'carrot' |
| oc-mitt.svg | https://openclipart.org 'mitten' |
| oc-button-red.svg · oc-button-line.svg | https://openclipart.org 'sewing button' |

openclipart 그림은 CC0(퍼블릭 도메인)라서 마음대로 쓰고 고쳐도 됩니다.
앱에 넣으면서 눈사람에 맞게 크기와 기울기만 `deco.js` 에서 맞췄습니다.
